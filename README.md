# نظام إدارة الحراسات الأمنية

تطبيق ويب لإعدادات المنشأة والمظهر، وإدارة الأقسام، وتقارير الموظفين، ومساعد عربي محدود الأوامر للمسؤول. الواجهة تتطلب اتصالاً بقاعدة بيانات MySQL.

## التشغيل

1. ثبّت Node.js 16.9 أو أحدث وMySQL، ثم ثبّت الاعتماديات باستخدام `npm install`.
2. أنشئ قاعدة البيانات والجداول عبر تشغيل `database/schema.sql` من مجلد المشروع على MySQL.
3. أنشئ ملف `.env` في جذر المشروع، واضبط `DB_HOST` و`DB_USER` و`DB_PASSWORD` و`DB_NAME` و`DB_PORT`، إضافة إلى `JWT_SECRET` عشوائي بطول 32 حرفاً على الأقل. لا تستخدم قيمة افتراضية أو ترفع الملف إلى Git.
4. استخدم حساب MySQL مخصصاً بصلاحيات على قاعدة بيانات التطبيق فقط، ولا تستخدم حساب `root` لتشغيل التطبيق.
5. أضف حساب مسؤول إلى جدول `employees` بدور `مدير` وحالة `نشط`. يجب أن تكون كلمة المرور مجزأة بـ bcrypt؛ أنشئ التجزئة محلياً باستخدام المكتبة `bcryptjs` المثبتة، ولا تستخدم كلمات المرور أو التجزئات الوهمية في `database/seed-data.sql`.
6. شغّل `npm start` وافتح `http://localhost:3000`. للدليل الصحي استخدم `/api/health`.

مثال آمن نسبياً لتوليد تجزئة كلمة مرور دون إظهارها على الشاشة أو وضعها في سجل الأوامر:

```sh
read -s -p "Password: " PASSWORD; echo
export PASSWORD
node -e "require('bcryptjs').hash(process.env.PASSWORD,12).then(console.log)"
unset PASSWORD
```

استخدم HTTPS في النشر الفعلي، مع إبقاء قاعدة البيانات غير مكشوفة للإنترنت.

صفحات الإدارة وواجهات API محمية بدور مدير. إعدادات المظهر والأقسام تحفظ في قاعدة البيانات؛ تقارير الموظفين تعرض بيانات وظيفية وتسمح بالتصفية حسب القسم والحالة.

## مساعد المسؤول

المساعد ينفذ فقط أوامر محددة مسبقاً، مثل `أضف قسم الدعم الفني`، `غيّر لون الواجهة إلى أخضر`، `غيّر الخلفية إلى فاتحة`، `غيّر اسم المنشأة إلى شركة الأمن`، و`اعرض تقرير الموظفين`. الطلبات الأخرى تحفظ في قائمة مراجعة المسؤول ولا تتحول تلقائياً إلى شيفرة أو وحدات جديدة. لا ترسل كلمات مرور أو أرقام هويات أو بيانات حساسة في الطلبات؛ سجل الطلبات محدود بآخر 50 عنصراً في الواجهة.

عند تحديث قاعدة بيانات موجودة، أعد تشغيل `database/schema.sql` لإضافة جدول `admin_requests` الجديد؛ أوامر إنشاء الجداول تستخدم `IF NOT EXISTS`.

## الكاميرات

تكامل الكاميرات غير مفعل. يلزم تحديد مُصنّع/طراز الأجهزة أو منصة إدارة الفيديو، وواجهات الربط المتاحة، ومتطلبات الشبكة والصلاحيات قبل بناء التكامل. لا تُدخل روابط بث أو بيانات اعتماد الكاميرات في إعدادات عامة.

## الاختبارات

يشغّل `npm test` Jest؛ لا توجد حالياً مجموعة اختبارات في المستودع.
